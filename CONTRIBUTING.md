# Contributing

Thanks for contributing to Customer Feedback Analyzer.

## Submitting Issues and Pull Requests

- Open an issue to report bugs, request features, or suggest improvements.
- Submit pull requests with a clear summary of the problem, the proposed change, and any relevant examples.
- Keep pull requests focused and easy to review.

## Content and Style Guidelines

- Markdown files should follow the included templates and project structure.
- All sample data must use fictional companies — never real customer data.
- Pull requests that include real customer information will be rejected.
- HTML dashboards must remain self-contained with no external CDN dependencies.

## Data Safety Expectations

- Remove or anonymize customer names, email addresses, account IDs, and other sensitive details.
- Double-check generated examples and screenshots before submitting a pull request.
